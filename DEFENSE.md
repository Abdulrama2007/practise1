# Как объяснить проект на защите

## Что сказать в начале

«Я разработал графический эмулятор UNIX-оболочки для варианта 21.
Он принимает команды пользователя и работает с виртуальной файловой
системой, загруженной из XML. Все обычные операции выполняются в памяти.
Интерфейс реализован на tkinter, язык — Python».

## Как проходит одна команда

Пользователь вводит `cd /home/student` и нажимает Enter.
Метод Terminal.submit читает строку и передаёт её в Shell.execute.
Метод split разделяет строку на `cd` и `/home/student`.
Диспетчер находит обработчик change_directory.
VFS.resolve проходит по папкам home и student.
Если папка существует, меняется cwd и приглашение в окне.
Если пути нет, выводится ошибка и текущая папка остаётся прежней.

## Почему файлы виртуальные

XML описывает дерево: папки, имена файлов и содержимое.
При загрузке каждый объект становится Node в памяти.
Папка содержит словарь children, файл — последовательность байтов data.
Программа не создаёт эти файлы на настоящем диске.
Например, rmdir удаляет элемент из словаря children.
Поэтому повторная загрузка исходного XML возвращает удалённую папку.

## Пять этапов

1. Создал окно, простой парсер, заглушки ls/cd, exit и сообщения об ошибках.
2. Добавил параметры запуска и выполнение команд из стартового файла.
3. Добавил XML-дерево в памяти, base64 и служебный сброс vfs-init.
4. Реализовал ls, cd, pwd и du.
5. Реализовал rmdir и подготовил проверки всех режимов и ошибок.

Каждый этап записан отдельным Git-коммитом с сообщением в формате
Conventional/Scoped Commits, например `feat(vfs): ...`.

## Что показать преподавателю

Откройте demo.bat. Затем введите команды вручную:

```text
pwd
ls -a /
cd /home/student/documents
pwd
ls
du
du -s /
cd ..
rmdir empty
ls
cd /
rmdir home
cd missing
ls -z
unknown
vfs-init
pwd
ls
exit
```

`rmdir home`, `cd missing`, `ls -z`, `unknown` намеренно показывают ошибки.
В конце vfs-init сбрасывает рабочий файл runtime/demo.xml, не пример.
Покажите также test.bat и историю `git log --oneline --reverse`.

## Частые вопросы

**Что такое REPL?** Цикл: прочитать строку, выполнить, вывести ответ,
снова ждать ввода. В GUI ожидание реализовано циклом событий tkinter.

**Что такое VFS?** Виртуальная файловая система — собственное дерево
файлов и папок внутри программы.

**Зачем base64?** XML текстовый, а файл может содержать любые байты.
Base64 позволяет записать эти байты печатными символами, затем восстановить.
Размер du считается после восстановления, а не по длине строки base64.

**Как работает du?** Для файла берётся len(data), для папки рекурсивно
суммируются размеры дочерних объектов. Единица измерения — байт.

**Что делает pwd?** Возвращает сохранённую строку cwd.

**Почему нельзя удалить непустую папку?** Таково поведение rmdir.
Для удаления объектов с содержимым понадобилась бы другая команда.

**Что делает vfs-init?** Создаёт стандартное дерево и меняет исходный XML
на его представление. Это служебное исключение из операций только в памяти.

**Что происходит при ошибке скрипта?** Сообщение выводится в диалоге,
далее выполняется следующая строка. exit завершает весь сеанс.

**Почему кавычки не поддерживаются?** В варианте 21 требуется простой
парсер по пробелам. Имена внутри VFS с пробелами запрещены.

**Почему du отличается от настоящего UNIX?** Настоящий du обычно измеряет
выделенные блоки диска. В этой VFS нет физических блоков, поэтому считается
объём содержимого в байтах; это явно описано в README.

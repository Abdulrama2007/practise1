# Эмулятор UNIX-оболочки: вариант 21

Практическая работа по конфигурационному управлению, ИКБО-18-25.
Язык: Python 3.10+. Зависимости: только стандартная библиотека.

## Этап 1

Окно терминала, реальные username/hostname, простой разбор по пробелам,
заглушки ls и cd, команда exit, обработка неверных команд и аргументов.

Запуск: `python -m src.main` или `run.bat` в Windows.
Проверки: `python -m unittest discover -s tests -v`.

Примеры: `ls`, `cd documents`, `unknown`, `exit extra`, `exit`.
